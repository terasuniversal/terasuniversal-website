# TERAS Admin CMS v1.2.0

## Release notes

- Courses: controlled draft, publish, archive and restore workflow.
- Training schedules: trainer assignment, capacity tracking, participant assignment and overlap checks.
- Participants: validation, duplicate IC/Passport handling, filtered exports and reviewed imports.
- Attendance and assessments: individual and bulk operational updates with exports.
- Certificates: eligibility checks, controlled generation, verification tokens, templates, reissue and revocation.
- Public verification: certificate-number and QR-token lookup, with private personal data withheld.
- Trainers and companies: operational profiles, search, filters, history and export surfaces.
- Reporting, Audit Log and Automation Centre: operational KPIs, traceability and import/certificate activity.
- Production hardening: protected routes, role gates, password recovery, safer image uploads, responsive admin shell and System Health.

## Upgrade notes

Apply repository migrations in order through `0021_automation_centre.sql` and the provision compatibility migration before deploying code. Regenerate Supabase types after the connected schema is current.

## Non-secret configuration

Use `.env.example` as the approved variable checklist. Keep service-role and Resend API keys server-side only.
