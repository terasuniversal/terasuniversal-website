# Attendance Guide

1. Create or open a training schedule and assign participants.
2. Open **Attendance**, choose the schedule, then mark present, late, absent or excused.
3. Record check-in, check-out and remarks where required.
4. Use bulk actions only after checking the selected rows.
5. Export the sheet for controlled offline records.

Attendance is a certificate eligibility input; verify it before assessments and certificate generation.
