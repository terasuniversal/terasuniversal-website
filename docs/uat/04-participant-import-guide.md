# Participant Import Guide

1. Open **Participants → Import**.
2. Use the supplied CSV headings exactly: participant details, company and contact fields.
3. Upload the file and inspect the preview before committing.
4. Correct rows marked invalid; do not force import them.
5. The system rejects duplicate IC/Passport values and records the import in Automation Centre/Audit Log.

Export filtered results first if you need a rollback reference.
