# Admin User Manual

## Sign in and daily use

1. Open `/admin/login` and sign in with your staff email.
2. Use the left navigation to open only the modules relevant to your role.
3. Search from the top bar by participant, company, course, schedule, certificate, trainer, news or download.
4. Use **Sign out** when leaving a shared computer.

## Permissions

- Editor: read operational records and manage website content.
- Trainer: attendance and assessment only.
- Admin: creates, edits, imports, generates certificates and changes system settings.
- Super Admin: all Admin rights plus user/role management.

If a page shows **No access**, ask a Super Admin to check your role.
