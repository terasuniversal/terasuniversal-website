# Troubleshooting Guide

| Symptom | First action |
| --- | --- |
| Cannot sign in | Confirm email/password, then use **Forgot password**. |
| No access page | Ask a Super Admin to verify the assigned role. |
| Import row invalid | Correct the highlighted field; do not bypass validation. |
| Certificate not eligible | Check attendance, assessment result and competency. |
| Upload failed | Confirm it is an image up to 5 MB, then retry. |
| Verification not found | Confirm the certificate number/token and check certificate status. |
| System error | Note the time, URL and action; then contact the administrator. |

For recurring errors, review the Audit Log, Automation Centre and System Health before escalating.
