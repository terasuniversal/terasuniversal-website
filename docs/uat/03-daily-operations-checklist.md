# Daily Operations Checklist

- [ ] Check System Health: database connected and no failed automation jobs.
- [ ] Check upcoming schedules and pending certificate notifications.
- [ ] Review imports before committing them.
- [ ] Confirm attendance and assessment records before certificate generation.
- [ ] Review the Audit Log after sensitive changes.
- [ ] Sign out after work, especially on shared devices.

## Weekly

- [ ] Review inactive or duplicate participant records.
- [ ] Review certificates due to expire or revoked certificates.
- [ ] Confirm Supabase backup status and storage usage.
