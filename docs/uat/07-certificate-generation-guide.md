# Certificate Generation Guide

1. Open **Certificates → Generate**.
2. Select a schedule and review the eligibility list.
3. Generate one certificate first when using a new template; then generate the remaining eligible participants.
4. Confirm the certificate number, verification link and public verification result.
5. Revoke or reissue only with an authorised reason; the audit trail is retained.

Never generate a certificate for an ineligible participant.
